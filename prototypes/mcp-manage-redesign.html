R3扫描纳管规则（列表 → 接管确认）

铁律：扫描只回元数据（键名不含值，密钥由后端按 target+key 重读取盘）；应用时先接管——等价则删未托管同名条目再写 xiaobai_；不等价则报错跳过该目标、文件原样保留。

现状
  • 一键纳管 + 逐条纳管混在一起，不知道哪条会被“接管”、哪条会冲突
  • 等价 / 不等价只在后端报错里出现，前端无预告
新版
  • 三态标签：可纳管 等价·将接管 冲突·将跳过，逐条说明后果
  • 纳管前确认弹窗列出“删谁 / 写谁 / 跳过谁”，密钥字段只显示键名
