## 关键改进点

### 1. 信息架构优化
**Before:**
- 主表单
  - 高级配置 (Collapse)
    - 站点信息 (Divider)
    - 代理配置 (Divider)
  - Codex 私有能力 (Collapse)

**After:**
- 主表单
  - 基础信息 (视觉分组，非 Collapse)
  - 可选配置 (Collapse)
  - Codex 高级能力 (Collapse)

### 2. 字段重新分配

| 字段 | 当前位置 | 改进位置 | 理由 |
|------|---------|---------|------|
| 连接协议 | 高级配置 > 站点信息 | 基础信息 | 影响功能，必须可见 |
| 测试连接 | 高级配置 > 站点信息 | 基础信息 | 高频操作，提升可达性 |
| 写入预览 | 高级配置 > 站点信息 | 可选配置 | 低频功能，保持折叠 |
| NewAPI 令牌 | 高级配置 > 代理配置 | 可选配置 | 合并简化 |
| HTTP 头部 | 高级配置 > 代理配置 | 可选配置 | 合并简化 |
| Codex 能力 | 单独 Collapse | 单独 Collapse | 保持独立性 |

### 3. 交互改进

#### 3.1 HTTP 头部编辑器
**Before:**
```javascript
// JSON 字符串编辑，容易出错
{
  "Authorization": "Bearer xxx",
  "X-Custom": "value"
}
```

**After:**
```
┌─────────────────────────────────────┐
│ □ 启用自定义 HTTP 头部              │
│                                     │
│ 键名              值                │
│ [Authorization] [Bearer xxx   ] ❌  │
│ [X-Custom     ] [value        ] ❌  │
│ [+ 添加头部]                        │
└─────────────────────────────────────┘
```

#### 3.2 自动保存展开状态
```typescript
// 记住用户的展开偏好
const [optionalOpen, setOptionalOpen] = useState(() => {
  const saved = localStorage.getItem('siteForm.optionalOpen');
  return saved ? JSON.parse(saved) : false;
});

useEffect(() => {
  localStorage.setItem('siteForm.optionalOpen', JSON.stringify(optionalOpen));
}, [optionalOpen]);
```

#### 3.3 编辑时智能展开
```typescript
// 如果某个折叠区有值，编辑时自动展开
useEffect(() => {
  if (site?.newapiToken || site?.proxyHeaders) {
    setOptionalOpen(true);
  }
  if (site?.capabilities && anyCodexCapabilityOn(site.capabilities)) {
    setCapOpen(true);
  }
}, [site]);
```

### 4. 文案优化

| 当前 | 改进 | 原因 |
|------|------|------|
| 高级配置 | 可选配置 | "高级"让新手望而却步 |
| 站点信息 | (删除) | 语义重复，不需要 |
| 代理配置 | (合并到可选配置) | 减少层级 |
| Codex 私有能力 | Codex 高级能力 | "私有"容易误解 |
| NewAPI 令牌 | NewAPI 中转令牌 (可选) | 更清晰的说明 |
| HTTP 头部 | 自定义 HTTP 头部 (高级) | 明确用途 |

## 用户流程对比

### 添加新站点

**Before (7 步):**
1. 填写显示名称
2. 填写 Base URL
3. 填写 API Key
4. 展开"高级配置"
5. 选择连接协议
6. 点击"测试连接"
7. 点击"保存"

**After (5 步):**
1. 填写显示名称
2. 填写 Base URL
3. 填写 API Key
4. 选择协议并点击"测试连接"
5. 点击"测试并保存"

### 编辑带代理的站点

**Before (6 步):**
1. 打开编辑对话框
2. 展开"高级配置"
3. 滚动到"代理配置"
4. 修改 NewAPI 令牌
5. 关闭"高级配置"
6. 点击"保存"

**After (3 步):**
1. 打开编辑对话框（自动展开"可选配置"）
2. 修改 NewAPI 中转令牌
3. 点击"保存"
